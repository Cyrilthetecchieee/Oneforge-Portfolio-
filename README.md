## Overview

Single-page interactive studio portfolio built for **ONEFORGE®** featuring a real-time **Three.js (`r0.160.0`) WebGL physics sphere field**, scroll-driven 3D stage choreography, custom color palette presets, and responsive glassmorphic editorial UI.

### Key Highlights
- **Real-Time WebGL Gravity Field**: 96 physical matte & transmission glass spheres rendered with dynamic lighting, cursor repulsion physics, and smooth scroll-driven transitions:
  1. **Hero Float**: Elliptical floating cluster behind the hero typography.
  2. **Gravity Drop & Floor Bounce**: Spheres surrender to gravity with restitution damping across the About & Services section.
  3. **Heart Silhouette**: Spheres reassemble into a 3D parametric heart formation in the Process section.
  4. **Weightless Release**: Spheres lift off and drift past the camera into the lens through Founders & Contact.
- **13 Core Capabilities**: Software Development, Web Development, Mobile Applications, Custom Software, Cloud Services, API Integrations, Maintenance & Support, Business Automation, UI/UX Design, Data Analytics, Digital Marketing, Branding & Creative Design, and Technical Consulting.
- **Studio Controls Drawer**: Live 3D sphere & gradient theme switcher (`Cobalt Blue`, `Champagne Gold`, `Emerald Matrix`, `Rose Quartz`, `Obsidian Slate`, `Cyber Violet`).
- **Zero Build Step**: Self-contained `index.html` using native ES Modules and CDN `importmap`.

## Running Locally

Because `index.html` uses ES Module `<script type="importmap">`, serve the folder over any local HTTP server:

```bash
# Using Node.js / npx
npx serve .

# Or using Python
python -m http.server 3000
```

Then open `http://localhost:3000` in your browser.
